# SETFLOW

スマートフォンでも操作しやすい、筋トレ用の日本語タイマーです。サーバーやアカウント登録は不要です。

## セット & 休憩

1セット目から開始します。セットを終えたら大きな「休憩をスタート」ボタンを押してください。休憩終了時にセット数が1つ進みます。休憩はデフォルト60秒、1〜3600秒で設定できます。種目を変えるときはリセットして1セット目に戻します。

## タバタ

デフォルトはスクワット、プッシュアップ、マウンテンクライマー、ジャンピングジャックの4種目を2セット。各種目は負荷20秒・休憩10秒、合計4分です。最終種目の休憩10秒も含みます。種目は選択・追加・削除可能（1〜12種目）。セット数は1〜20です。開始後は自動で進みます。

両モードとも一時停止・再開に対応。音をオンにすると切り替え時に通知音を鳴らします。対応ブラウザではタイマー中の画面消灯を抑えます。

## ブラウザの制約

画面ロックやバックグラウンドではブラウザがタイマーや音声を停止する場合があります。画面を開いて使用してください。画面へ戻った際は実際の経過時間から表示を補正します。ページの再読み込みで設定と進行状況はリセットされます。

## ローカル実行・検証

静的HTTPサーバーでこのディレクトリを配信してください（例: `python -m http.server 8000`）。ビルドや依存ライブラリのインストールは不要です。

```sh
node --test engine.test.mjs
node --check app.js
```

GitHub Pages は `main` ブランチのルートを公開します。フォント以外は外部サービスへ依存しません。
